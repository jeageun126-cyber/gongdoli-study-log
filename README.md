# 공돌이 AI·SW 실험실 4편 — Study Log

3편에서 공개한 B 프롬프트로 ChatGPT가 생성한 **공부 시간 기록 웹앱 원본 코드**입니다. HTML·CSS·JavaScript가 `index.html` 한 파일에 들어 있습니다.

## 실행 방법

1. GitHub 저장소의 **Code → Download ZIP**을 눌러 내려받고 압축을 풉니다.
2. Visual Studio Code에서 압축을 푼 폴더를 연 뒤 `index.html`을 엽니다.
3. VS Code 확장 프로그램 **Live Server (Ritwick Dey)**를 설치하고 상태 표시줄에서 `Go Live`를 누릅니다.
4. 브라우저에 열린 로컬 주소에서 날짜, 과목, 공부 시간을 입력합니다.

Python 3가 정상 설치되어 있다면 해당 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`에 접속하는 방법도 가능합니다.

**주의:** `index.html`을 그냥 더블클릭해 `file://`로 열 경우 브라우저마다 `localStorage`의 동작이 다를 수 있습니다. 로컬 HTTP 서버 사용을 권장합니다.

## 기능

- 선택 날짜에 공부 과목과 시간(1~1440분 정수)을 등록
- 해당 날짜의 기록 목록 및 총 공부 시간 표시
- 기록 개별 삭제 및 합계 갱신
- 브라우저의 `localStorage`에 저장된 기록 불러오기
- 모바일 크기 반응형 레이아웃

## 실제 실습에서 확인한 내용

Windows·Microsoft Edge·VS Code Live Server (`http://127.0.0.1:5500/index.html`)에서 사용자가 아래 항목을 직접 확인했습니다.

- 웹페이지 첫 실행, 정상 기록 추가, 30분+60분 합계, 개별 삭제
- F5 새로고침 후 데이터 유지
- 과목 미입력·0분·1441분 저장 거부
- 다른 날짜로 이동했다가 돌아왔을 때 기존 기록 확인
- Edge 개발자 도구 400×611px에서 주요 입력 영역 및 기록 목록 배치 확인

실제 휴대폰 조작, 다양한 브라우저, 날짜 유효성의 모든 경우, 저장소 오류 등은 아직 충분히 검증하지 않았습니다. 테스트 데이터를 실제 공부 실적으로 해석하지 마세요.

## 주의 및 한계

- 기록은 **해당 브라우저·사이트 주소에만** 저장됩니다. 자동 클라우드 동기화가 없습니다.
- 브라우저의 사이트 데이터 삭제·비공개 창 종료 등으로 기록이 사라질 수 있습니다. 중요한 데이터를 유일한 저장소로 사용하지 마세요.
- 개인 학습용 초안입니다. 보안·접근성·극단값·광범위한 호환성 테스트를 완료한 상용 서비스가 아닙니다.
- 이 저장소의 `index.html`은 B 결과물의 HTML 코드 블록을 **프로그램 로직을 바꾸지 않고 분리**한 버전입니다. 실습 도중 원본에 섞여 들어간 Markdown 구분자 및 안내 문장은 포함되지 않습니다.
